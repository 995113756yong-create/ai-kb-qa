# 云笔记 Pro 数据安全与合规说明

## 一、数据存储位置

国内客户的数据存储于中国大陆境内机房，可选北京、上海、广州三个地域。
境外客户可选新加坡、法兰克福地域。跨地域数据不会自动同步。

## 二、加密方案

### 2.1 传输加密

所有客户端与服务器之间的通信强制使用 TLS 1.3。
旧版 TLS 1.0 / 1.1 已完全禁用。API 调用需启用双向证书校验。

### 2.2 存储加密

静态数据使用 AES-256-GCM 加密，密钥由 KMS 托管并每 90 天自动轮转。
加密粒度为「文档级」，即每篇文档使用独立的数据密钥，
数据密钥再被主密钥封装。这样即使单篇文档的密钥泄露，也不影响其他文档。

### 2.3 端到端加密

专业版支持可选的工作区级端到端加密。
开启后服务端无法解密文档内容，代价是全文检索与协作编辑不可用。
私有部署版默认不开启端到端加密。

## 三、访问控制

### 3.1 身份认证

支持账号密码、企业 SSO（SAML 2.0 / OIDC）、扫码登录三种方式。
管理员可强制要求全体成员启用双因素认证（TOTP）。
连续 5 次密码错误锁定账号 30 分钟。

### 3.2 审计日志

记录所有敏感操作：登录、导出、权限变更、删除、恢复。
审计日志保留 180 天，专业版可延长至 3 年。
审计日志本身不可被管理员删除，仅可导出。

### 3.3 最小权限原则

默认新建成员为「访客」角色，需管理员显式提升权限。
导出功能默认关闭，需单独授权。

## 四、数据生命周期

| 阶段 | 说明 |
|---|---|
| 创建 | 文档写入即生成版本记录 |
| 使用 | 按角色权限访问，每次访问记审计日志 |
| 归档 | 团队可手动归档长期不用的笔记本，归档后不占活跃配额 |
| 删除 | 进入回收站保留 30 天，期间可恢复 |
| 彻底清除 | 回收站到期后 7 天内从所有副本物理删除 |

备份数据保留 35 天，采用「3-2-1」策略：3 份副本、2 种介质、1 份异地。

## 五、合规资质

已通过 ISO/IEC 27001、ISO/IEC 27701 认证。
支持等保三级要求，私有部署版可提供等保测评所需材料。
数据处理协议（DPA）可按客户要求签署。

## 六、安全事件响应

发现安全事件后 24 小时内通知受影响客户，
72 小时内提供初步分析报告，30 天内提供完整复盘。
重大事件同步上报监管机构。
