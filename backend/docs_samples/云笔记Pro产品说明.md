# 云笔记 Pro 产品说明

## 一、产品定位

云笔记 Pro 是面向中小团队的协作文档工具，聚焦「写下来、找得到、传得开」三件事。
与面向个人的免费版不同，Pro 版提供团队空间、权限管理和版本历史。

## 二、版本与价格

|---|---|---|---|---|

## 三、核心功能

### 3.1 团队空间

一个团队空间可以容纳多个笔记本，每个笔记本下有多篇文档。
成员按角色分三档：

- **管理员**：可增删成员、修改团队设置、导出全部数据
- **编辑者**：可创建与修改文档，不能改团队设置
- **访客**：只读，且看不到未分享给他的文档

### 3.2 权限管理

支持文档级与目录级权限。文档级权限优先级高于目录级。
举例：某目录对全体成员只读，其中一篇文档可单独设为「编辑者可写」。

### 3.3 版本历史

每次保存自动生成一个版本，标准版保留 90 天，专业版永久保留。
可以对比任意两个版本的差异，也可以把文档回滚到某个历史版本。
回滚本身也会生成一个新版本，不会删除原有版本记录。

### 3.4 全文检索

基于倒排索引，支持中文分词。检索范围包括正文、标题、附件名。
检索结果按相关度排序，标题命中的权重高于正文命中。

## 四、限制说明

- 单篇文档上限 5 MB
- 单个附件上限 100 MB，标准版最多 20 个附件
- 免费版不支持 API 访问
- 私有部署版不提供移动端 App，仅支持网页与桌面客户端

## 五、技术支持

标准版工作日 8 小时内响应，专业版 4 小时内响应，私有部署配备专属技术经理。
